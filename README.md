# JellySin Trakt

Trakt integration for Jellyfin 12: scrobbling, watched-history and collection
sync, ratings, watchlists and lists, written against the current
[Trakt API](https://trakt.docs.apiary.io/).

It is a project of the [JellySin](https://github.com/jellysin) organisation.
JellySin: Jellyfin plus sin, a little temptation for your media server; said
JELLY-sin. The sibling plugin is
[jellysin/plugin-lastfm](https://github.com/jellysin/plugin-lastfm).

> Status: in development. No release yet.
